# Installing

You need a laptop with a web browser: Chrome, Edge, Safari or Firefox. You do not need a GitHub account, and you do not need to install anything else.

## Step 1: download the game

1. Go to the project's page on GitHub (the page where you found this guide).
2. Near the top right of the file list there is a green button labelled **Code**. Click it.
3. A small menu opens. At the bottom of it, click **Download ZIP**.
4. Your browser downloads a file called **gate_agent_-master.zip**. It usually goes into your **Downloads** folder.

## Step 2: unpack the ZIP file

A ZIP file is a folder squeezed into one file. You need to unpack it before the game will open properly.

**On Windows**

1. Open **File Explorer** (the yellow folder icon on the taskbar) and click **Downloads** on the left.
2. Right-click **gate_agent_-master.zip** and choose **Extract All…**
3. A window opens. Click **Extract**.
4. A new folder called **gate_agent_-master** appears and opens.

**On a Mac**

1. Open **Finder** and click **Downloads** on the left.
2. Double-click **gate_agent_-master.zip**.
3. A new folder called **gate_agent_-master** appears next to it.

## Step 3: open the game

1. Open the **gate_agent_-master** folder.
2. Double-click **morning-wave.html**.
3. The game opens in your web browser, showing **MORNING WAVE** at the top and a dark departures board on the left.

## Make it easy to find again

- **Bookmark it.** With the game open, press **Ctrl + D** on Windows or **Cmd + D** on a Mac and save the bookmark.
- **Move the folder somewhere safe.** If you leave it in Downloads you may delete it by accident. Drag the **gate_agent_-master** folder to **Documents**, then open the game from there and bookmark it again.

If the game opens as a page of code instead of a game, or does not open at all, see [Troubleshooting](07-Troubleshooting.md).
