# Updating to a newer version

1. Download the new version the same way you installed it: green **Code** button, then **Download ZIP**.
2. Unpack it as before.
3. Replace your old **morning-wave.html** with the new one. The easiest way: delete your old **gate_agent_-master** folder, then move the new one to the same place.
4. Open the new **morning-wave.html**.

## Will I lose my progress?

Usually not. Your progress is kept by your browser, not in the folder. Chrome and Edge keep it for any game file you open on your laptop. Safari and Firefox can treat a file in a different place as a different game, so keep the new file in the same folder as the old one.

If your progress does disappear, nothing is broken: the training day and shift 1 are always open, and you can work back up.
