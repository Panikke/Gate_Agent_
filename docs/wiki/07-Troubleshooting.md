# Troubleshooting

| What you see | What to do |
| --- | --- |
| The game opens as a page of code | You opened it in a text editor. Right-click **morning-wave.html**, choose **Open with**, and pick your web browser |
| A message about files in a ZIP, or the game opens but looks broken | You opened it from inside the ZIP without unpacking. Go back to [Installing, step 2](02-Installing.md) |
| The letters look plain and different from the screenshots | You are offline, so the fonts could not load. The game works the same |
| My progress has gone | You may be in a private or incognito window, which forgets everything when closed, or in a different browser. Open the game in a normal window of the browser you used before |
| **Start the shift** is greyed out | The game is still working out the medal targets for this wave. Wait two or three seconds |
| Everything is red after **New wave** | That is expected: a new wave starts with nothing assigned |
| A bar will not drag up or down | Its aircraft is already on stand, so it can only be held with more delay (dragged right) |
| The timeline is cut off at the right | Scroll sideways inside the timeline panel, or make the browser window wider |

Still stuck? Open an issue on the GitHub page: click the **Issues** tab, then **New issue**, and describe what you did and what you saw.
